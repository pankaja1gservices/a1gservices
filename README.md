**Trust + Professionalism + Transparency + Speed + Personal Attention**

Do NOT make it look like a generic loan website, cheap template, or aggressive sales landing page.

The visual language should feel similar to a high-end private financial advisory firm.

Use:

* Deep navy / midnight blue as the primary brand color
* White and soft off-white backgrounds
* Subtle cyan/blue accent inspired by the existing business card
* Minimal gold accent where appropriate
* Generous whitespace
* Elegant typography
* Soft shadows
* Subtle gradients
* Premium cards with restrained borders
* Smooth micro-interactions
* Professional financial imagery
* Clean icons

The existing A1 Global Financial Consultant logo from the supplied visiting card should inspire the visual identity. If the logo cannot be extracted, recreate a clean, minimal A1-style globe/financial mark rather than inventing an unrelated logo.
